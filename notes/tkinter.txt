Tkinter
    - Tkinter is the standard, built-in library in Python used to create Graphical User Interfaces (GUIs).

.Tk()
    - Creates a new window and configurations
    - window = Tk()


.mainloop()
    - A method that tells your Python program to start listening for user interactions 
      and keeps your application window from immediately closing
    - window.mainloop()
.title()
    - Assigns a title to you window
    - window.title("title_here")
.minsize(width=, height=)
    - Sets minimum size for window
    - window.minsize()
.config()
    - Configure attributes
    - window.config(padx=, pady=, bg=)
        - Configure padding
        - Configure background color with hexcode
.after({milliseconds}, {function}, {args})
    - For timer


.Label(text=, font=("Arial", 8, "bold"))
    - A Label is a widget used to display static or dynamic text and images on your user interface.
    - It is purely informational, meaning users can look at it, but they cannot click it like a button or type inside it like a text box.
    - variable = Tkinter.Label(text=)
    - You need to apply .pack() to initialize it or .grid() or .place()
.pack()
    - If you call .pack() with no arguments, Tkinter simply stacks your widgets vertically from top to bottom, centered horizontally.
    - You have to have a Label object first
    - .pack(expand=1)
        - Boolean, 0 or 1
    - .pack(side=)
        - left, right, top, bottom
    - Can't mix pack() and grid()
.place(x=, y=)
    - Position the widget with X and Y axis
.grid(column=, row=)
    - Sets the position by column and rows
    - Can't mix pack() and grid()
    - columnspan attribute = value is how many columns you want it to stretch to
